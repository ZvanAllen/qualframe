# Demo dataset: adopting an AI documentation assistant

Six fictional interviews from two fictional primary care clinics, written for demonstrating
QualFrame. They are not research data and describe no real people or organisations.

- `transcripts/` — plain-text interviews, one folder per site
- `codebook.yaml` and `codebook.xlsx` — an original 15-code directed codebook (four categories)
- `metadata.csv` — site and role for each interview

The codebook was written for this demo. It is loosely inspired by common implementation
determinant categories but is not a published framework.
