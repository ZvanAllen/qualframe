# Reference and development records

These documents were written during QualFrame's research-prototype phase (August and September 2026): product specifications, data-model notes, evaluation and benchmarking protocols, and dated development checkpoints. They are kept for transparency and for the methods papers in preparation.

They describe intentions and verification at the time they were written. For how QualFrame works now, see the [user guide](../guide.md), [models and data](../models-and-data.md) and the [development notes](../development.md). Where they disagree, the current guides and the code take precedence.

Useful starting points:

- [architecture.md](architecture.md) and [domain_model.md](domain_model.md): engine design and data model
- [prompt_inventory.md](prompt_inventory.md): where the CFIR prompts came from
- [evaluation_protocol.md](evaluation_protocol.md), [benchmark_metric_notes.md](benchmark_metric_notes.md), [archival_comparator_protocol.md](archival_comparator_protocol.md): evaluation designs
- [privacy_governance.md](privacy_governance.md): data-handling principles
