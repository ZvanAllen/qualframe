# September 12: preparation while API funding is pending

This increment prepares CFIR methods/evaluation work and the local public beta.
It makes no new provider calls. Historical transcripts, outputs and human review
records remain unchanged, and private research artifacts are excluded from public
packages.

## Implemented offline

- **Historical reference import and comparison:** source/reference hash checks,
  explicit parent hierarchy, retained exclusions, symmetric quotation alignment
  and one-to-one evidence retrieval with threshold and boundary sensitivities.
  Synthetic tests and an existing private development output exercise the path.
- **Broader synthesis preparation:** a separately versioned five-domain prompt
  and immutable request builder, with local domain/network/valence validation.
  Existing network artifacts can be prepared without dispatching requests.
- **Release verification:** stronger exact-member packaging and private-file
  screening, isolated Windows installation, offline demos, and same-study app
  restart. Test receipts identify the exact archive and interpreter.
- **Research preparation:** private manuscript and blank results-table drafts,
  source/configuration allocation slots, metric/reporting conventions, reference
  inventories, a synthetic tutorial storyboard and landing-page copy draft.

## Boundaries and remaining work

The historical comparator is human-reviewed AI-assisted analysis. It does not
establish independent human labels, exhaustive negative decisions, original
adjudication events or exact historical source-version identity. Expanded-context
quote matches measure location/code concordance. The proposed no-new-rating study
does not claim semantic accuracy, human-human reliability, measured time savings
or equivalence to human analysis.

Planned runs remain unexecuted. Funding, current model snapshots/settings,
provider-specific governance and fixed synthesis input snapshots must be resolved
before execution. Repetition counts and reporting conventions alone do not freeze
an executable provider configuration. The broader synthesis preparer has no
dispatcher. A private development comparison cannot fill controlled-study results
tables or support landing-page model-performance claims.

Physical macOS installation and external usability testing are pending. The
current CFIR website workbook has not been cleared for bundled redistribution;
the [attribution record](cfir_attribution_and_distribution.md) distinguishes
article licenses from the exact downloadable asset. No release or promotional
material is published by this preparation round.
