# QualFrame capability status

Current product state: September 12, 2026. The public checkout is authoritative.
Target specifications and historical AMN outputs do not establish general product
validation. Earlier dated checkpoints preserve the history of individual changes.

The first public beta targets research teams with one operator per study, local
storage, Windows/macOS, researcher-supplied API keys, Excel codebooks, and
agreement/stability evaluation. The tutorial is November 11. Complete review is
the initial policy; human-reference calibration and sampled review follow later.

## API evidence and scientific boundaries

The September 8 synthetic checks authenticated OpenAI and Anthropic. Initial
model-offset outputs were invalid; a versioned exact-quotation contract then
produced two source-valid coding rows per provider in the remaining approved
calls. Total recorded cost across those four calls was USD 0.0050812. See
[API results](api_smoke_results_2026-09-08.md). These small tests establish software
behavior, not qualitative accuracy or general model performance.

The private, owner-approved CFIR transcript walkthrough completed six GPT-5.2
coding requests and reached human review. It does not establish the fresh
browser-upload paid workflow or a fully adjudicated analysis. No private inputs
or derived research outputs belong in public releases.

The cached five-stage CFIR demo remains a reference workflow with historical AMN
roll-up/context/network assumptions. It consumes previous-stage raw model
artifacts; it is distinct from synthesis of reviewed snapshots.

The September 10 browser/API checks exercised a fresh fictional transcript upload,
three coding calls per provider, and reviewed-input synthesis. A malformed OpenAI
synthesis response prompted schema-constrained generation; the failed response and
charge were preserved. See [test results](api_synthesis_results_2026-09-10.md).
No scientific accuracy or stability estimate follows from these tiny fixtures.
