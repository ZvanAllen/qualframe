# Roadmap

This public snapshot preserves a working research prototype, not a completed general-purpose analysis product. The [capability register](capability_status.md) is the detailed status map.

## Delivered foundation

- Typed configuration and versioned file-backed prompts.
- Transcript-first CFIR reference pipeline plus the earlier workbook-first runner.
- Provider adapters, dry runs, filters, crash recovery, provenance, QA, and exports.
- Optional local stage/release controls and append-only adjudication.
- Generic method, codebook, evidence-span, assignment, and configuration contracts.
- Cost ledger, configured ceilings, approval pauses, and an unverified email adapter.
- Local study creation, validated source import, core method editing, and mock/cached background execution.
- Source-linked generic evidence review and reviewed JSON/Excel packages.
- Shared responsive browser design, real synthetic screenshots, offline launchers, and public release checks.

## Next: complete the researcher workflow

1. Provider, review, analysis, cost, and custom partition-group editors.
2. Human-coded calibration with complete review before promotion.
3. Sequential model/effort comparison against an approved calibration sample.
4. Complete, risk-based, random, and combined post-calibration review policies.
5. Metadata-defined analysis with evidence-linked matrices and a full methods appendix.
6. Direct text-selection evidence editing and a legacy-CFIR exact-evidence adapter.

Every increment needs synthetic tests, explicit capability boundaries, and preservation of the CFIR reference method. Provider-backed checks are separately authorized and cost-gated.

## Deliberately later

Hosted multi-tenant deployment, authenticated roles, universal inductive analysis, and automatic publication-ready interpretation are not current build targets.
