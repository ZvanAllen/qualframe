# 0006 — Public beta scope and authoritative development baseline

Accepted by the owner on September 7, 2026.

QualFrame is free MIT-licensed software for research teams working through one operator per study. It targets Windows and macOS with local storage and researcher-supplied API keys. Initial exchange formats are Excel codebooks, TXT/DOCX transcripts, and CSV metadata.

The public Git history is the authoritative development baseline. The enclosing historical research workspace is an archive, not another product branch. A clean clone lives at `public_app/` in that workspace; older release directories are frozen snapshots. Releases are packaged from this same codebase with content auditing. Private research data and manuscript drafts stay outside the product checkout.

The November 11, 2026 tutorial is the delivery target. October 28 is the demo freeze. Windows/macOS are support targets; neither installer support nor remote macOS verification is claimed by adding a CI job.

This decision supersedes 0001's initial individual-user positioning and 0004/0005's calibration-first release sequence. One operator manages the team's local study; concurrent editing and hosted accounts remain later work. The first comparison release assesses inter-configuration agreement and within-configuration stability. Human-reference calibration and validated model promotion follow later. Complete human evidence review remains the initial policy. No agreement score is presented as accuracy or validity.

Grouping is optional and study-defined; AMN network labels remain unchanged in the compatibility template. Parent aggregation is optional and distinct from narrative synthesis. Display context is configurable and separate from exact coded evidence. Framework packs require source/version/citation and redistribution review.

Live calls still require explicit provider configuration, governance, a spending ceiling, and applicable approval. This scope decision does not authorize API spending or publication.
