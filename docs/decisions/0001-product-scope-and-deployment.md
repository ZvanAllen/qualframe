# 0001: Product scope and deployment

- Status: accepted
- Date: 2026-08-02

## Decision

QualFrame targets the broader category of human-supervised directed and framework-based qualitative content analysis. CFIR is the first mature reference method.

The first user is an individual researcher. The first end-user product is a local-first browser application backed by the existing Python engine, local state, and file-based immutable artifacts. Cloud hosting, accounts, and multi-user permissions are deferred.

## Consequences

UX and performance are first-class requirements. The current CLI and loopback dashboard remain useful foundations but are not the target product experience. Public materials must distinguish the current implementation from the target platform.
